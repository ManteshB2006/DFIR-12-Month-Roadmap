# DFIR Career Preparation

Use this guide after building foundational knowledge and completing several practical investigations.

## Entry-level roles to research
- SOC Analyst (L1)
- Security Operations Analyst
- Junior Incident Response Analyst
- Digital Forensics Intern
- DFIR Intern
- Security Analyst

Role titles vary. Some entry-level positions combine monitoring, triage, and incident handling rather than full forensic acquisition.

## Skills to demonstrate
- Windows and Linux fundamentals
- Networking and packet analysis
- Windows Event Logs and endpoint artefacts
- Evidence integrity, hashing, and documentation
- Disk and memory forensic fundamentals
- Incident triage, timeline construction, and reporting
- SIEM searches and alert investigation
- Clear communication of findings and uncertainty

## Portfolio checklist
- [ ] PCAP investigation
- [ ] Windows event-log investigation
- [ ] Windows artefact examination
- [ ] Disk-image investigation
- [ ] Memory-forensics investigation
- [ ] SIEM or incident-response case
- [ ] Threat-hunting report
- [ ] Integrated capstone

## Interview preparation
Practise explaining:
- Acquisition versus analysis
- Why evidence hashes and chain of custody matter
- How to preserve a potentially compromised endpoint
- What Windows artefacts can indicate program execution
- How to build and validate an incident timeline
- What memory forensics can reveal that disk analysis may not
- How to investigate a suspicious network connection
- How to distinguish evidence from assumptions
- How to communicate uncertainty and limitations

## Presenting a project
1. What happened in the scenario?
2. What was the scope and what evidence was available?
3. Which tools and methods did you choose, and why?
4. What did you observe?
5. How did you validate your interpretation?
6. What could you not establish?
7. What would you recommend next?

## CV guidance
Use accurate, action-oriented descriptions, for example:
- Analysed a training PCAP in Wireshark, identified key hosts and protocols, and documented a timestamped network timeline.
- Examined Windows event logs and correlated authentication and process activity in a simulated incident.
- Acquired and verified a test forensic image, then examined file-system artefacts in Autopsy.

Label training work as labs, simulations, or independent research. Do not claim professional incident-response experience based solely on lab projects.
