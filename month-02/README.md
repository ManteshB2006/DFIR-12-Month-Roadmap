**Goal:** Build command-line, operating-system and basic scripting skills.

## Learning and tools
Google certificate Linux/Python/SQL modules; Ubuntu shell, PowerShell, Python 3, Event Viewer.

## Weekly tasks

- [ ] Review prerequisites and monthly objectives.

### Week 2 — Practise
- [ ] Complete the next learning block.

### Week 3 — Investigate
- [ ] Complete the main practical investigation:
- [ ] Create a Linux command notebook
- [ ] inspect Windows users/services/logs in VM

- [ ] test edge cases.
- [ ] Create an evidence inventory and draft findings.
- [ ] Use the project-plan and evidence-log templates.

### Week 4 — Publish and review
- [ ] Finish lessons and revise weak concepts.
- [ ] Complete the monthly deliverable.
- [ ] Write the investigation report and peer-review it.
- [ ] Update certificate and project trackers.
- [ ] Complete weekly review and plan the next month.
