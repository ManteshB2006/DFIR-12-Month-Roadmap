# Digital Forensics & Incident Response — 12-Month Roadmap

A beginner-friendly, practical roadmap for building DFIR skills over 12 months.

## Starting point
- Starting level: complete beginner
- Suggested commitment: 3 hours per day, 6 days per week
- Goal: build practical forensic and incident-response skills, complete documented investigations, and create a portfolio.

This repository focuses on DFIR learning and practical career preparation only. It does not cover university academic recovery or postgraduate admissions planning.

## Daily study structure
| Time | Activity |
|---|---|
| 60 minutes | Learn concepts and make concise notes |
| 90 minutes | Complete a hands-on lab |
| 30 minutes | Document commands, evidence, findings, and questions |

## Roadmap
| Months | Focus |
|---|---|
| 1–2 | IT, networking, Linux, and Windows foundations |
| 3–4 | Windows artefacts and event-log analysis |
| 5–6 | Evidence handling, disk acquisition, and file-system forensics |
| 7 | Memory forensics with Volatility 3 |
| 8 | Network forensics with Wireshark and Zeek |
| 9 | SIEM and incident-response fundamentals |
| 10 | Threat hunting, YARA, Velociraptor, and MITRE ATT&CK |
| 11 | Safe malware and ransomware investigations |
| 12 | End-to-end capstone and portfolio |

## Working principles
- Investigate only systems and data you own or are authorised to examine.
- Preserve original evidence and analyse verified working copies.
- Record timestamps, time zones, tool versions, commands, and hashes.
- Distinguish observed facts from hypotheses.
- Use isolated disposable virtual machines for risky analysis.
- Never publish private, personal, or confidential evidence.
