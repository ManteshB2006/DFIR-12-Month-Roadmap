# Portfolio Projects

Track all projects in [PROJECT-TRACKER.md](../PROJECT-TRACKER.md).

## Project workflow
1. Create a project folder (for example `P08-PCAP-Investigation`).
2. Copy [PROJECT-PLAN.md](../templates/PROJECT-PLAN.md).
3. Use a lawful, synthetic or explicitly authorised dataset.
4. Record evidence IDs, SHA-256 hashes, tool versions and UTC timestamps.
5. Write the report using [INVESTIGATION-REPORT.md](../templates/INVESTIGATION-REPORT.md).
6. Remove secrets, personal data and restricted artefacts before publication.

## Practice resources
- [CyberDefenders](https://cyberdefenders.org/) — blue-team and DFIR challenges.
- [Blue Team Labs Online](https://blueteamlabs.online/) — defensive investigation exercises.
- [13Cubed](https://www.youtube.com/@13Cubed) — Windows and memory forensics learning.
- [Autopsy](https://www.autopsy.com/) — forensic platform and documentation.

Review dataset licences and lab rules before use. Keep large evidence files out of Git; publish reproducible notes, scripts, hashes and redacted screenshots.
