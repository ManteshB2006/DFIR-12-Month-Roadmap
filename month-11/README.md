# Month 11: Threat hunting & endpoint response

**Goal:** Move from alert-driven triage to hypothesis-driven investigation.

## Learning and tools
MITRE ATT&CK, Velociraptor and SIEM fundamentals; sample logs in an authorised lab.

## Weekly tasks
### Week 1 — Learn
- [ ] Review prerequisites and monthly objectives.
- [ ] Complete the first learning block.
- [ ] Record concepts, commands and tool versions.

### Week 2 — Guided practice
- [ ] Complete a guided exercise on a lawful sample dataset.
- [ ] Record observations and evidence references.
- [ ] Verify hashes and preserve source artefacts.

### Week 3 — Main investigation
- [ ] Write hunt hypothesis
- [ ] map expected behaviours to ATT&CK
- [ ] search authorised telemetry
- [ ] document positive and negative results
- [ ] propose detection improvements.
- [ ] Draft the project plan, evidence inventory and timeline.

### Week 4 — Report and review
- [ ] Complete the monthly deliverable.
- [ ] Write findings with supporting evidence and limitations.
- [ ] Peer-review, sanitise and publish the report.
- [ ] Update trackers and complete weekly review.

## Monthly deliverable
Threat-hunting case study and detection proposal.

## Exit criteria
Explain hypothesis, telemetry, ATT&CK mapping and confidence.
