# Month 12: Capstone & career preparation

**Goal:** Demonstrate an end-to-end reproducible investigation and prepare for junior roles.

## Learning and tools
Revise disk, Windows, memory, network and IR skills; finish selected courses.

## Weekly tasks
### Week 1 — Learn
- [ ] Review prerequisites and monthly objectives.
- [ ] Complete the first learning block.
- [ ] Record concepts, commands and tool versions.

### Week 2 — Guided practice
- [ ] Complete a guided exercise on a lawful sample dataset.
- [ ] Record observations and evidence references.
- [ ] Verify hashes and preserve source artefacts.

### Week 3 — Main investigation
- [ ] Define scope
- [ ] preserve evidence
- [ ] triage host/network artefacts
- [ ] build UTC timeline and IOC list
- [ ] map supported behaviour
- [ ] write executive and technical reports
- [ ] peer-review and sanitise.
- [ ] Draft the project plan, evidence inventory and timeline.

### Week 4 — Report and review
- [ ] Complete the monthly deliverable.
- [ ] Write findings with supporting evidence and limitations.
- [ ] Peer-review, sanitise and publish the report.
- [ ] Update trackers and complete weekly review.

## Monthly deliverable
End-to-end DFIR capstone, 8–10 polished portfolio entries, resume and interview notes.

## Exit criteria
Explain the case from alert to evidence, findings, limitations and recommendations.
