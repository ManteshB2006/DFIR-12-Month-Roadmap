# DFIR Portfolio Projects

Build these projects progressively. Each project should contain a clear README, methodology, evidence references, safe screenshots, and a concise conclusion.

## Project 1 — PCAP investigation
Analyse a network capture and explain relevant communications. Include the PCAP source and licence, Wireshark filters, hosts, protocols, timestamps, observations, limitations, and conclusion.

## Project 2 — Windows event-log investigation
Reconstruct a simulated endpoint activity sequence. Include the EVTX dataset source, relevant event IDs and fields, account and process activity, a timezone-aware timeline, and alternative explanations.

## Project 3 — Windows artefact examination
Explain what selected Windows artefacts reveal about user and program activity. Include artefact types, parser used, records and timestamps, interpretation, caveats, and cross-validation.

## Project 4 — Disk-image examination
Examine a training disk image. Include acquisition details and hashes if you performed acquisition, image and partition information, relevant files and metadata, deleted-file findings if applicable, timeline, and report.

## Project 5 — Memory investigation
Examine a memory capture for suspicious process or network activity. Include capture provenance, Volatility 3 version and plugins, process and connection findings, correlation, and limitations.

## Project 6 — SIEM incident investigation
Investigate a simulated alert using endpoint or authentication logs. Include alert context, searches and queries, timeline, affected entities, triage decision, and escalation recommendation.

## Project 7 — Threat-hunting report
Test a behaviour-based hypothesis against lab telemetry. Include the hypothesis, MITRE ATT&CK mapping, data sources and queries, results, false positives, telemetry gaps, and detection improvements.

## Project 8 — Ransomware simulation case study
Investigate a safe simulated ransomware incident. Include scenario and scope, evidence-preservation priorities, endpoint and network findings, timeline, ATT&CK mapping, containment and recovery recommendations.

## Final capstone report structure
1. Executive summary
2. Scope and authorisation
3. Evidence inventory and integrity
4. Methodology and tools
5. Timeline
6. Findings and supporting evidence
7. Indicators and ATT&CK mapping
8. Impact and scope assessment
9. Response recommendations
10. Limitations and lessons learned

## Publishing safely
Only publish sanitised reports and permitted datasets. Remove personal data, credentials, sensitive private IP details, proprietary logs, and confidential information. Never upload raw evidence unless you have the right to distribute it.
