# Month 01: Networking & lab setup

**Goal:** Understand TCP/IP, DNS, HTTP/S, ports, OS basics and virtual lab isolation.

## Learning and tools
Google Cybersecurity Certificate networking modules; VirtualBox, Ubuntu, Windows VM, Wireshark.

## Weekly tasks
### Week 1 — Learn
- [ ] Review prerequisites and monthly objectives.
- [ ] Complete the first course lessons.
- [ ] Record notes and unfamiliar terms.
- [ ] Confirm lab isolation and tool versions.

### Week 2 — Practise
- [ ] Complete the next learning block.
- [ ] Perform a guided exercise.
- [ ] Record commands, observations and questions.
- [ ] Save a short lab journal.

### Week 3 — Investigate
- [ ] Complete the main practical investigation:
- [ ] Map your lab
- [ ] capture benign traffic
- [ ] identify DNS queries, TCP handshake and TLS metadata
- [ ] document a network baseline.
- [ ] Create an evidence inventory and draft findings.
- [ ] Use the project-plan and evidence-log templates.

### Week 4 — Publish and review
- [ ] Finish lessons and revise weak concepts.
- [ ] Complete the monthly deliverable.
- [ ] Write the investigation report and peer-review it.
- [ ] Update certificate and project trackers.
- [ ] Complete weekly review and plan the next month.

## Monthly project
Lab diagram, tool inventory and network baseline notes.

## Exit criteria
Explain IP addressing, DNS, TCP handshake and safe VM isolation.
